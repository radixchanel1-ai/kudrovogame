# Захват Кудрово — онлайн-игра в Telegram

Карта Кудрово поделена на 100 районов-сот. Все игроки делят одну общую карту, прогресс хранится на сервере.
Названия районов задаёт только админ (ты), игроки поменять их не могут.

## Файлы
- `server.py` — бот, игровой сервер и API в одном файле
- `static/index.html` — само мини-приложение (карта, тапы)
- `requirements.txt` — зависимости

## Запуск бесплатно (без VPS)

Понадобятся три бесплатных аккаунта: GitHub, Supabase (база данных) и Render (сервер).

### 1. Бот
@BotFather → `/newbot` → сохрани токен.

### 2. Код на GitHub
Создай репозиторий на github.com → «Add file» → «Upload files» → загрузи `server.py`, `requirements.txt`
и папку `static` (с `index.html` внутри).

### 3. База данных — Supabase
1. supabase.com → New project. Регион — Frankfurt (ближе всего). Придумай пароль базы и сохрани его.
2. Кнопка **Connect** → вкладка **Session pooler** → скопируй строку вида
   `postgresql://postgres.xxxx:[YOUR-PASSWORD]@aws-0-eu-central-1.pooler.supabase.com:5432/postgres`
3. Замени `[YOUR-PASSWORD]` на свой пароль. Это `DATABASE_URL`.

### 4. Сервер — Render
1. render.com → New → **Web Service** → подключи свой репозиторий.
2. Настройки:
   - Runtime: **Python**
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python server.py`
   - Instance Type: **Free**
3. Environment Variables:
   - `BOT_TOKEN` — токен бота
   - `DATABASE_URL` — строка из Supabase
   - `BASE_URL` — адрес сервиса, Render показывает его вверху страницы (например `https://kudrovo-game.onrender.com`)
   - `PYTHON_VERSION` — `3.12.4`
   - `ADMIN_IDS` — пока оставь пустым
4. Deploy.

### 5. Стать админом
1. Напиши боту `/myid` — он пришлёт твой Telegram ID.
2. В Render → Environment → `ADMIN_IDS` = этот ID → Save → сервис перезапустится.
3. Открой игру, нажми на район → «✏️ Название». Так назови все нужные районы.

## Правила
- 10 тапов = воин (сила 1), 100 тапов = пушка (10), 1000 тапов = танк (100).
- Первый район можно захватить где угодно, дальше — только соседние со своими.
- Сила больше обороны — район твой. Меньше — армия погибает, но оборона врага слабеет.
- «Укрепить» переносит армию в оборону своего района.
- 🏆 — рейтинг игроков по числу районов.

## Полезно знать
- Бесплатный Render засыпает через 15 минут без игроков. Первое открытие после этого занимает около минуты.
- Бесплатный проект Supabase ставится на паузу, если неделю никто не играл. Включается кнопкой
  «Resume project» в панели Supabase, данные сохраняются.
- Границы карты и размер районов настраиваются в начале `server.py` (`BOUNDS`, `HEX_RADIUS_M`).
  Если поменять их после запуска, районы и захваты на карте собьются, поэтому лучше настроить до старта игры.
- Защита от автокликеров: сервер засчитывает не больше 15 тапов в секунду.
